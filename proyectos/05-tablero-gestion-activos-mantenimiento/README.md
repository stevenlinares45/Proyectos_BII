# Tablero de Gestión de Activos y Servicio Técnico — Power BI

**Sector del cliente:** Corporativo — operaciones y mantenimiento
**Rol:** Modelado de datos, desarrollo del reporte

> ℹ️ Proyecto real para un cliente corporativo. Nombres de cliente y datos operativos **no se muestran** por confidencialidad.

## Contexto y problema

El cliente registra sus tickets de servicio técnico (autorizaciones, anotaciones y seguimiento de actividades) en un sistema de gestión de activos, pero carecía de un tablero analítico para ver tendencias, tiempos de atención y volumen de casos por tipo.

## Enfoque

Consolidación de las exportaciones del sistema de gestión de activos (autorizaciones, anotaciones, actividades) en un modelo único en Power BI, permitiendo análisis de volumen y seguimiento que antes solo existían como registros individuales dentro del sistema operacional.

## Stack técnico
`Power BI (PBIP)` · `Modelado de datos` · `Consolidación de fuentes CSV`

## Resultado
Vista analítica del histórico de servicio técnico, complementando al sistema operacional (pensado para el registro caso a caso, no para el análisis agregado).
